# Shanti Logbook

ct as an expert UI/UX designer and Next.js frontend developer. I am building a personal blogging website where I will document my learnings. The frontend is built with Next.js and Tailwind CSS.

I have finalized my design tokens and need you to help me design the UI and generate the Tailwind configuration for the application.

My Design Tokens:

Primary Font: Shanti

Color Palette: 2E2910, 2C5745, EBE3A7, EB7D00

The Requirements:

Please apply this design system to the following three core pages. The overall vibe should be [insert vibe, e.g., minimal, highly readable, dark-mode focused, developer-centric].

1. The Dashboard (Home):

A clean landing page displaying a list of my published articles. It should include a simple navbar, and the article cards/list items should show the title, date, and a brief excerpt.

2. The Article Reading Page:

A highly readable layout optimized for long-form text and code snippets (Markdown rendered). Please define the typography hierarchy (H1, H2, H3, paragraphs) and how inline code and code blocks should be styled using the color palette.

3. The Admin Panel (Protected):

A secure, functional workspace. It needs a minimal layout with a large text area for writing Markdown on one side, and a live preview of the rendered Markdown on the other. Include a simple "Publish" button using the Accent color.

Deliverables I need from you:

The tailwind.config.js file extending the default theme with my specific colors and fonts.

The globals.css file structure (if any custom CSS variables are needed).

A conceptual React component breakdown or code wireframe for how you would structure the Dashboard and Article Reading pages using Tailwind classes.
